Política de privacidad

Última actualización: octubre de 2026

Responsable

Esta web la gestiona Javier González-Jurado, que opera como THE GASP COMPANY®, con sede en Madrid (España). Para cualquier consulta sobre privacidad, escribe a info@thegasp.eu.

Cookies y analítica

Esta web no usa cookies ni herramientas de analítica. No tiene formularios, cuentas de usuario ni publicidad.

Si nos escribes

Si escribes a info@thegasp.eu, usamos tu nombre, tu correo y lo que nos cuentes solo para responderte y, si acabamos trabajando juntos, para preparar un presupuesto o un contrato. No te añadimos a ninguna lista de correo. Puedes pedirnos que borremos esa correspondencia en cualquier momento.

Alojamiento

La web está alojada en GitHub Pages. Como cualquier servidor, GitHub puede registrar datos técnicos, como tu dirección IP, por motivos de seguridad y para mantener el servicio. No tenemos acceso a esos registros ni los usamos. Consulta la declaración de privacidad de GitHub para más detalles.

Tus derechos

De acuerdo con el RGPD, puedes pedir el acceso, la rectificación o la supresión de los datos personales que tengamos sobre ti, u oponerte a su uso, escribiendo a info@thegasp.eu. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).
